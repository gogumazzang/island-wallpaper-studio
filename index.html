사진은 이 브라우저 안에만 저장되고 어디에도 자동으로 보내지 않아요. 캐릭터를 만들 때는 같은 사진 파일을 주민대표/ 폴더에 넣어 주세요. 대화창에서 Claude가 그 파일을 본인 Canva 계정(비공개)에 올려 참고로 써요.

📏 고정 스타일 규칙

이미지 생성 시 항상 적용할 규칙입니다 (4단계 프롬프트에 고정).

  • Animal Crossing: New Horizons 게임 속 실제 스크린샷 느낌
  • 부드럽고 둥근 3D 게임 그래픽, 게임 카메라 시점, 자연스러운 원근감
  • 일러스트·애니메이션풍 금지 / 극사실 사진 금지
  • 글자·워터마크·UI·로고·장식 프레임 금지
  • 캐릭터 없음, 풍경이 화면의 중심
  • 참고 이미지 공통점: 눈높이의 낮은 카메라, 화면 중간쯤의 수평선, 하늘이 화면의 절반 이상, 멀리 작은 섬 실루엣, 납작하고 부드러운 구름, 오브젝트는 작고 적게(1~3개)
